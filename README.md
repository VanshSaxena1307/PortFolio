# V-CITY | Vansh Saxena Portfolio

> **Software Engineer · Builder**  
> An interactive isometric virtual developer city, cinematic landing experience, case studies, and recruiter dossier.

---

## Architecture Overview

1. **Cinematic Landing Page**: High-impact scroll-driven introduction with quick navigation.
2. **V-City World**: Isometric spatial metropolis with districts, buildings, NPCs, and interactive camera.
3. **Project Case Studies**: In-depth architectural breakdowns, challenges, and measurable metrics.
4. **Recruiter Navigation Layer**: Quick-view dossier tailored for rapid scanning by recruiters and engineering managers.
5. **ECHO Hub**: Engineering philosophy, core stack DNA, and milestone tracking.
6. **Hire Me Communication Terminal**: Cyber-themed interactive terminal for direct transmissions.

---

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
